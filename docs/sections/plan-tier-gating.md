# Plan-Tier Gating

- All of the above governance controls require **Copilot Business or Enterprise** seats — Free/Pro/Pro+/Max plans carry no org/enterprise policy control.
- **Copilot included with GitHub Enterprise** (new, Oct 28 2026): enterprises working with a GitHub or Microsoft account team can get Copilot for every licensed GitHub Enterprise Cloud user; unlicensed users in the enterprise get the same access via **Copilot Standalone** ($10/user/month). Features and models match Copilot Enterprise, but there are no monthly AI credits per seat — AI usage is metered against the enterprise budget from the first request. Code completion and next edit suggestions work with no budget; Copilot Chat, code review and Copilot in the cloud need available budget. Self-serve availability is not yet open; Copilot Business and Enterprise remain purchasable ([changelog](https://github.blog/changelog/2026-10-28-github-enterprise-now-includes-access-to-github-copilot), [docs](https://docs.github.com/copilot/get-started/whats-changing-with-github-enterprise-and-copilot)). Whether the policy controls apply identically to this access path is not stated in the post — see [Known Gaps]({{ '/sections/known-gaps/' | relative_url }}).
- Copilot governance features are **GHEC (Enterprise Cloud) only** — not available on GitHub Enterprise Server.
