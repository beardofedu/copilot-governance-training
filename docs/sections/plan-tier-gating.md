# Plan-Tier Gating

- Organization/enterprise governance controls are available with **Copilot Business or Enterprise** seats, **Copilot included with GitHub Enterprise**, or **Copilot Standalone**; the latter two have the same features as Copilot Enterprise ([source](https://github.blog/changelog/2026-10-28-github-enterprise-now-includes-access-to-github-copilot)). Free/Pro/Pro+/Max plans carry no org/enterprise policy control.
- Copilot governance features are **GHEC (Enterprise Cloud) only** — not available on GitHub Enterprise Server.

### Copilot included with GitHub Enterprise (Oct 28, 2026)

- Enterprises working with a GitHub or Microsoft account team can now get Copilot included with GitHub Enterprise for every licensed user. Users without a GitHub Enterprise license get the same access through **Copilot Standalone** ($10 per user per month). Both have the same features and models as Copilot Enterprise but **no monthly AI credits per seat** ([source](https://github.blog/changelog/2026-10-28-github-enterprise-now-includes-access-to-github-copilot)).
- AI usage is metered from the first request against the enterprise budget. Code completion and next edit suggestions keep working with no budget; Copilot Chat, Copilot code review, and Copilot in the cloud require available budget. An exhausted budget never removes the seat ([source](https://github.blog/changelog/2026-10-28-github-enterprise-now-includes-access-to-github-copilot)).
- Available now for GitHub Enterprise Cloud via an account team; self-serve availability is rolling out in stages with dates not yet published. Copilot Business and Copilot Enterprise remain available ([source](https://github.blog/changelog/2026-10-28-github-enterprise-now-includes-access-to-github-copilot)).
