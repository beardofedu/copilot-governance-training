# Plan-Tier Gating

- The governance controls described in this guide are available through **Copilot Business or Enterprise** seats, **Copilot included with GitHub Enterprise**, or **Copilot Standalone** — Free/Pro/Pro+/Max plans carry no org/enterprise policy control.
- Copilot governance features are **GHEC (Enterprise Cloud) only** — not available on GitHub Enterprise Server.
- **GitHub Enterprise can now include Copilot (Oct 28, 2026):** enterprises working with a GitHub or Microsoft account team can get Copilot included with GitHub Enterprise for every licensed user. Users without a GitHub Enterprise license get the same access through **Copilot Standalone** ($10 per user per month). Both have the same features and models as Copilot Enterprise but **no monthly AI credits per seat**; usage is metered from the first request against the enterprise budget. Self-serve availability is coming in stages, and Copilot Business and Copilot Enterprise remain available. ([changelog](https://github.blog/changelog/2026-10-28-github-enterprise-now-includes-access-to-github-copilot), [Copilot access docs](https://docs.github.com/copilot/get-started/whats-changing-with-github-enterprise-and-copilot), [billing docs](https://docs.github.com/copilot/concepts/billing-and-usage/organizations-and-enterprises/billing))
