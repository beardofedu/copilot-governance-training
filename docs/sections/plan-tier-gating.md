# Plan-Tier Gating

- The governance controls described in this guide are available through **Copilot Business or Enterprise** seats, **Copilot included with GitHub Enterprise**, or **Copilot Standalone** — Free/Pro/Pro+/Max plans carry no org/enterprise policy control.
- Copilot governance features are **GHEC (Enterprise Cloud) only** — not available on GitHub Enterprise Server.
- **Copilot included with GitHub Enterprise** (GitHub Enterprise Cloud, via a GitHub or Microsoft account team): every licensed user gets Copilot with the same features and models as Copilot Enterprise, but without monthly AI credits per seat. Usage is metered against the enterprise budget from the first request; unlicensed users in the enterprise get the same access through **Copilot Standalone** ($10 per user per month). Code completion and next edit suggestions work with no budget; Copilot Chat, code review, and Copilot in the cloud need available budget. Self-serve availability is staged, with dates not yet announced; Copilot Business and Copilot Enterprise remain available.
