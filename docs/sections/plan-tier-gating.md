# Plan-Tier Gating

- All of the above governance controls require **Copilot Business or Enterprise** seats — Free/Pro/Pro+/Max plans carry no org/enterprise policy control.
- Copilot governance features are **GHEC (Enterprise Cloud) only** — not available on GitHub Enterprise Server.
- Enterprises working with a GitHub or Microsoft account team can now get Copilot included with **GitHub Enterprise** for every licensed user; unlicensed users in the enterprise get the same access through **Copilot Standalone** ($10 per user per month). Both carry the same features and models as Copilot Enterprise but no monthly AI credits per seat, so enterprise budget is the primary control. Code completion and next edit suggestions keep working with no budget; Copilot Chat, code review, and Copilot in the cloud need available budget, and an exhausted budget never removes access. Self-serve availability is coming in stages; Copilot Business and Enterprise remain available ([changelog](https://github.blog/changelog/2026-10-28-github-enterprise-now-includes-access-to-github-copilot)).
