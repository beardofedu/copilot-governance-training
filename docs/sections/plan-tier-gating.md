# Plan-Tier Gating

- These governance controls are available with **Copilot Business or Enterprise** seats, **Copilot access included with GitHub Enterprise**, or **Copilot Standalone**, as described below. Free/Pro/Pro+/Max plans carry no org/enterprise policy control.
- Copilot governance features are **GHEC (Enterprise Cloud) only** — not available on GitHub Enterprise Server.

## Copilot included with GitHub Enterprise (account-team customers)

> **Official sources**
> - [GitHub Enterprise now includes access to GitHub Copilot](https://github.blog/changelog/2026-10-28-github-enterprise-now-includes-access-to-github-copilot)
> - [Copilot access with GitHub Enterprise](https://docs.github.com/copilot/get-started/whats-changing-with-github-enterprise-and-copilot)

| Topic | Behavior |
|---|---|
| Availability | Enterprises working with a GitHub or Microsoft account team can get Copilot included for every licensed GitHub Enterprise user (GitHub Enterprise Cloud). Self-serve availability is rolling out in stages with dates not yet announced; existing self-serve subscriptions are unaffected. |
| Users without a GitHub Enterprise license | Same access through **Copilot Standalone** at $10 per user per month. |
| Features and models | Same as Copilot Enterprise, but **no monthly AI credits per seat**. |
| Budget | AI usage is metered from the first request against the enterprise budget. Code completion and next edit suggestions keep working with no budget; Copilot Chat, code review, and Copilot in the cloud need available budget. An exhausted budget never removes the seat. |
| Existing plans | Copilot Business and Copilot Enterprise remain available to buy. |
